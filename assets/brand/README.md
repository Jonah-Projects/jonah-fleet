## Visual Design System

### Seed Origin
The chromatic system and geometric ratios were procedurally extracted from the 64-character hash:
`bbf65d904db96f87e74619fc0f7eb9084bab829287cf8b14eda5b727a2c90c9b`

### Palette Specifications

| Role | Color Name | Hex Code | Purpose |
| :--- | :--- | :--- | :--- |
| **Base / Canvas** | Command Night | `#050811` | Dark mode backgrounds, CLI chrome, terminal backgrounds |
| **Primary Accent** | Radar Chartreuse | `#BBF65D` | Target lock, active agent vectors, passing checks, primary CTA |
| **Secondary Energy**| Thruster Cobalt | `#4619FC` | Parallel subagent pulses, workflow dispatch signals |
| **Structural Alloy**| Battleship Slate | `#829287` | Coordinate axes, commit hashes, dividers, subtle borders |
| **Warning / Gate** | Ordnance Flare | `#CF8B14` | Drift warnings, unverified assertions, claim locks |

### Typography
- **Wordmark & Display**: High-contrast, wide-stance geometric grotesk or technical sans (e.g. *Eurostile*, *Chakra Petch*, or *Space Grotesk*).
- **Code & Telemetry**: *Departure Mono*, *JetBrains Mono*, or *Berkeley Mono*.
- **Body & Docs**: *Geist* or *Inter*.
